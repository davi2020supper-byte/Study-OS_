# Study OS — PWA ENEM 2027

Versão 2.0: painel semanal de estudos, calendário de segunda a sábado, timer de foco de 50 minutos e pausa de 10 minutos, conclusão de tarefas e estatísticas semanais.

## Publicar no GitHub Pages
1. Extraia este ZIP.
2. No repositório existente, envie/substitua os seis arquivos na raiz: `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js` e `README.md`.
3. Faça commit das alterações. O GitHub Pages atualizará o site automaticamente.

Os registros ficam salvos localmente no navegador do aparelho (`localStorage`). Não há login nem sincronização entre dispositivos nesta versão. O timer registra o tempo de foco concluído; marcar uma tarefa manualmente atualiza o progresso dos blocos.
